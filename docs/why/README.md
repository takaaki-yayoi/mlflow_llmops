# 章別「なぜ嬉しいのか」サマリ

本書 [`MLflowで実践するLLMOps`] は MLflow の機能を体系的に解説する構成になっており、紙面の都合で「この機能が現場のどんな課題に効くのか」「使わないとどうなるのか」の文脈を厚く書ききれていない箇所があります。本ディレクトリは、そのギャップを埋めるための **章別「なぜ嬉しいのか」サマリ** です。

各章 200〜300 字を目安に、次の 3 観点で書いています。

1. **どんな現場課題に効くか** — その機能が無いとき、現場で何が痛いか。
2. **使わないとどうなるか** — 採用しなかった場合のアンチパターン。
3. **本書の該当節と一緒に読むと良い箇所** — 本書だけだと言及が薄い実運用上の論点。

# 利用方法

- 本書を 1 章ずつ読み進めるとき、章を読む前に該当ファイルを開き「自分のチームではどの課題に効きそうか」を確認すると、本書の機能解説に「自分の文脈」が乗ります。
- すでに本書を読み終えた読者向けには、社内勉強会やチームへの紹介資料の素材としてもお使いいただけます。

# 補足や反論があれば

「自分のチームではむしろこの観点で効いた」「ここはこう書いた方が誤解が少ない」といった意見は、GitHub Issues で `why-discussion` ラベルを付けて議論にあげていただけると助かります。本ディレクトリは読者からのフィードバックを取り込んで継続的に改訂します。
