# 6.3 プロンプトの運用・改善戦略

## リスト6.8 プロンプトの評価 (重要な差分あり)

- **対応ファイル**: `prompts/04_evaluate_prompt.py`
- **実行**: `make eval`
- **重要な差分**:
  - **エージェントの種類**: 本書ではLangGraphAgentを使う前提で説明していますが、**第6章のリポジトリは独立構成のため OpenAI API を直接呼び出します**。エージェント統合版の評価は第5章のサンプルコードを参照してください。
  - **カスタムスコアラーの実装方式**:
    - 本書 リスト6.8: `make_judge` を使った LLMジャッジベースのスコアラー (`from mlflow.genai.judges import make_judge`)
    - リポジトリ: `@scorer` デコレータを使った独自LLM呼び出しベースのスコアラー (`from mlflow.genai.scorers import scorer`)
  - 両方とも有効な実装ですが、本書の説明と本リポジトリのコードで評価関数の実装方式が異なります。本書のリスト6.8 のコードをそのまま動かしたい場合は、本書のコードを別ファイルに保存して実行してください。

## リスト6.9 プロンプトのロールバック

- **対応ファイル**: `prompts/03_alias_management.py` または `prompts/07_deploy_lifecycle.py` (エイリアスの切り替え操作)
- **差分**: ロールバックは独立スニペットですが、リポジトリではライフサイクル管理スクリプトに統合されています。

## リスト6.10 プロンプトのA/Bテスト

- **対応ファイル**: `prompts/07_deploy_lifecycle.py` の段階的デプロイ機能内
- **差分**: A/B テストの抜粋が独立リストとして本書に記載されていますが、リポジトリではデプロイライフサイクルの一部として実装されています。

## リスト6.11 GEPAによるプロンプトの最適化

- **対応ファイル**: `prompts/06_optimize_gepa.py`
- **実行**: `make optimize-gepa`
- **コスト注意**: GEPAはLLMを多数回呼び出すため、実行コストが高く時間がかかります。`max_metric_calls` で呼び出し回数を制限してください。
- **追加スクリプト (本書未掲載)**: リポジトリには `prompts/05_optimize_metaprompt.py` も収録しています。これは MetaPromptOptimizer によるプロンプト構造改善の例で、ゼロショットでも動作する高速版です。本書では GEPA のみ言及されていますが、コスト・時間の制約がある場合は MetaPrompt の利用を検討してください。
